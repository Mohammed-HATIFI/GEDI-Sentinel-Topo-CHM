# Citations and References

## How to Cite This Code

If you use this repository in your research, please cite:

Use `CITATION.cff` for the current software citation. Add the article DOI only after
acceptance; do not publish placeholder journal, volume, page, or DOI values.

## Data Sources

- **GEDI** (Global Ecosystem Dynamics Investigation)
  - Dubayah, R., et al. (2020). The Global Ecosystem Dynamics Investigation (GEDI): A space mission to map forest structure. *Remote Sensing of Environment*, 258, 112365.
  - https://daac.ornl.gov/GEDI/

- **Sentinel-1 & Sentinel-2** (ESA Copernicus)
  - Drusch, M., et al. (2012). Sentinel-2: ESA's optical high-resolution mission for GEOS and land cover mapping. *Remote Sensing of Environment*, 120, 25-36.
  - https://dataspace.copernicus.eu/

- **SRTM** (Shuttle Radar Topography Mission)
  - https://earthexplorer.usgs.gov/

- **ESA WorldCover**
  - https://worldcover.vito.be/

- **Dynamic World**
  - https://www.dynamicworld.app/
